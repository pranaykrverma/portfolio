# 🍎 macOS Contacts Portfolio

A modern, interactive, and fully responsive portfolio website inspired by the macOS Contacts application. Designed to deliver a premium desktop-like experience with smooth animations, elegant UI components, and immersive interactions while showcasing projects, skills, achievements, and professional experience.

## ✨ Features

* macOS-inspired user interface and user experience
* Smooth page transitions and animations
* Interactive project showcase
* Responsive design for desktop, tablet, and mobile devices
* Dynamic contact and profile sections
* Performance-optimized architecture
* Modern component-based development approach
* Clean and scalable codebase

## 🛠️ Tech Stack

* Next.js 15
* React 19
* TypeScript
* Tailwind CSS
* Framer Motion
* GSAP
* Lenis Smooth Scroll
* Three.js
* Zustand
* Lucide Icons

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 📦 Production Build

```bash
npm run build
npm start
```
